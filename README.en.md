### 📌 Featured Projects

#### 🌐 Jungle In English — *Microservices Architecture, DevOps & Machine Learning*
Modular academic and social management platform built on a microservices architecture.
- **Backend/Frontend:** Spring Boot • Angular • Keycloak (centralized SSO)
- **DevOps:** CI/CD pipelines (Jenkins), Docker containerization, Kubernetes orchestration
- **Features:** learning paths, community spaces, performance dashboards
- **Machine Learning:** recruitment/staffing optimization, student dropout risk prediction, personalized study plan generation

🔗 [View project](https://github.com/BouthaynaHammami/Jungle_In_English)

#### 🏨 Hotel Brise Douce — *Hotel Management Platform*
Hotel booking platform built on a microservices architecture (9 independent services: customers, rooms, bookings, staff, maintenance, reviews, users).
- **Architecture:** centralized API Gateway, Service Discovery (Eureka), centralized Config Server
- **Communication:** asynchronous via RabbitMQ
- **Persistence:** MySQL • Docker containerization
- **Security:** OAuth2/JWT authentication with Keycloak
- **Frontend:** Angular 18 with Server-Side Rendering (Angular Universal)

🔗 [View project](https://github.com/BouthaynaHammami/Hotel-brise-douce)
