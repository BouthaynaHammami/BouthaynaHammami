## ⭐ Projets principaux

### 🌐 Jungle In English

**Microservices • Spring Boot • Angular • DevOps • Machine Learning**

Plateforme académique et sociale conçue selon une **architecture microservices**.

- 🔐 Authentification centralisée et SSO avec Keycloak
- 🚀 Docker, Kubernetes et CI/CD avec Jenkins
- 🤖 Machine Learning pour l'optimisation du recrutement, la prédiction du risque de décrochage et la personnalisation des plans d'étude

🔗 [Voir le projet](https://github.com/BouthaynaHammami/Jungle_In_English)

---

### 🏨 Hotel Brise Douce

**Microservices • Spring Boot • Angular • RabbitMQ • Docker**

Plateforme de gestion et de réservation hôtelière composée de **9 microservices indépendants**.

- 🏗️ API Gateway, Eureka Service Discovery et Config Server
- 📨 Communication asynchrone avec RabbitMQ
- 🔐 Authentification OAuth2/JWT avec Keycloak
- 💻 Frontend Angular 18 avec Server-Side Rendering

🔗 [Voir le projet](https://github.com/BouthaynaHammami/Hotel-brise-douce)
