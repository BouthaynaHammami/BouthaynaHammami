### 📌 Projets phares

#### 🌐 Jungle In English — *Architecture Microservices, DevOps & Machine Learning*
Plateforme modulaire de gestion académique et sociale basée sur une architecture microservices.
- **Backend/Frontend :** Spring Boot • Angular • Keycloak (SSO centralisé)
- **DevOps :** pipelines CI/CD (Jenkins), conteneurisation Docker, orchestration Kubernetes
- **Fonctionnalités :** parcours d'apprentissage, espaces communautaires, dashboards de performance
- **Machine Learning :** optimisation du recrutement/staff, prédiction du risque d'abandon des étudiants, génération de plans d'étude personnalisés

🔗 [Voir le projet](https://github.com/BouthaynaHammami/Jungle_In_English)

#### 🏨 Hotel Brise Douce — *Plateforme de Gestion Hôtelière*
Plateforme de réservation hôtelière basée sur une architecture microservices (9 services indépendants : clients, chambres, réservations, personnel, maintenance, avis, utilisateurs).
- **Architecture :** API Gateway centralisée, Service Discovery (Eureka), configuration centralisée (Config Server)
- **Communication :** asynchrone via RabbitMQ
- **Persistance :** MySQL • conteneurisation Docker
- **Sécurité :** authentification OAuth2/JWT avec Keycloak
- **Frontend :** Angular 18 avec Server-Side Rendering (Angular Universal)

🔗 [Voir le projet](https://github.com/BouthaynaHammami/Hotel-brise-douce)
